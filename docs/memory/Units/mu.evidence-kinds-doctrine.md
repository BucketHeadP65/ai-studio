## Statement

The standing trust doctrine, restated for agent evaluation: **any evidence kind is admissible under owner policy; self-assessment is not.**
A judge is a fallible instrument, so its output is evidence and never truth, and it must be independent of the agent it judges — a second,
independent argument for keeping judges out-of-band.

A verdict therefore ships as a **typed, signed evidence kind** carrying its own provenance: judge model, rubric version, sample count,
dispersion, per-step findings, redactions disclosed, signed-by. The field evidence for fallibility: the same trajectory scored 0.6 / 0.8 /
0.7 across three runs at temperature 0; usable signal required median-of-5 at 3× cost, and regression detection required paired-difference
tests on bootstrapped samples rather than compared means. The consequence is that suite deltas are statistical claims, not arithmetic ones —
a 50-case suite mostly measures its own noise unless it is treated statistically.

The doctrine is not local to agent evaluation. The memory-engineering thread's provenance-carrying units are the same shape (typed, signed,
provenance-first artifacts), which is why this unit is grouped under both threads; whether it is literally one doctrine with two surfaces is
still an open fork in [[bs.memory-engineering-lifecycle]] §6.
