# Compounding policy

## notes-to-analysis
Fold the open note threads on an initiative's files into its analysis.md, one finding per thread, numbered on from the last finding the analysis already carries, then answer each thread with the finding it became and resolve it.

## promote-initiative
An executed design promotes its durable decisions into an ADR the owner accepts. Write the ADR as proposed, one decision per ADR, absorbing the design and citing the initiative folder. The title carries no number, the id and the file do.
