## TL;DR

Each new note added to a well-indexed knowledge base becomes more valuable because it can be linked to existing notes, creating a network effect.

## Definition

Knowledge compounding refers to the phenomenon where the marginal value of adding a new knowledge item grows as the knowledge base expands, driven by the increasing number of potential connections.
